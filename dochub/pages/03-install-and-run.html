03 · Install & run

Native on Windows and Linux. Same source. No runtime other than the OS. Go 1.22+ to build; the binary itself needs nothing.

Reviewed 2026-08-14 Windows amd64 Linux amd64
Build First run Flags Cross-compile

Build

From the repo root.

HostCommandOutput
Windows go build -o gpewebdefender.exe .\cmd\gpewebdefender gpewebdefender.exe
Linux go build -o gpewebdefender ./cmd/gpewebdefender gpewebdefender
Windows → Linux set GOOS=linux · set GOARCH=amd64 · set CGO_ENABLED=0 · same go build gpewebdefender-linux-amd64 (~16 MB)
CGO is off on purpose SQLite is the pure-Go port. You do not need gcc on the build box or on the server.

First run

IntentCommandThen
See the UI with fake attacks gpewebdefender demo Open http://127.0.0.1:8787 — this is not your server.
Watch a real log (this box) gpewebdefender serve --tail C:\logs\access.log
or --tail /var/log/nginx/access.log		 Same UI. Source column is the file name.
Watch from another host Manager: serve --token SECRET --listen 127.0.0.1:8787
Remote: agent --url http://siem:8787 --token SECRET --tail …		 09
Default bind --listen defaults to 127.0.0.1:8787. Only this machine can open the UI. That is correct until you put a gate in front of it. See 10.

Cross-compile from Windows (PowerShell)

$env:GOOS="linux"
$env:GOARCH="amd64"
$env:CGO_ENABLED="0"
go build -o gpewebdefender-linux-amd64 .\cmd\gpewebdefender

Copy the file to the Linux box, chmod +x, run. No Go install required on the server.
