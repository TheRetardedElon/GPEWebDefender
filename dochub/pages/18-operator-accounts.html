18 · Operator accounts

People who open the dashboard are not agents. Operator passwords live in SQLite as Argon2id hashes. The ingest token never creates, lists, or resets those accounts.

Added 2026-08-15 v0.6.0

Why this exists

The ingest token is a machine secret. Every agent has it. If that token could also change the operator password or create admins, a stolen agent is a stolen dashboard. So after the first operator exists:

  • POST /api/ingest still uses Authorization: Bearer (the ingest token).
  • Every other /api/* path (except health / login / setup / auth-status) needs a session cookie.
  • Settings → Operators is how you create users and rotate your password.
nginx htpasswd is optional extra An outer basic-auth gate is still a good idea on a public hostname. It is not a substitute for operator accounts. This chapter is the in-app login.

Create the first admin

Pick one. Do not leave the manager reachable from the internet with zero users.

HowWhen
Open /login in the browser. The form becomes “create the first admin”. Default. The manager must not be on a public bind without nginx / a firewall.
Set SIEM_ADMIN_USER and SIEM_ADMIN_PASSWORD in the env file, start once, then delete the password line. Headless / first boot. The process logs a reminder.

Password rules: at least 12 characters, not the username, not a short list of common strings. After the first admin exists, POST /api/setup returns 409.

Roles

RoleCanCannot
admin Dashboard, search, reports, Settings writes, create / disable / delete users, reset their passwords, change own password Delete or disable the last remaining admin. See or set the ingest token.
viewer Dashboard, search, reports, change own password Create users, save Settings, reset anyone else’s password

How it is stored

ThingHow
PasswordArgon2id (t=3, 32 MiB, p=2). Never logged. Never returned by the API.
Session32-byte random token. Only the SHA-256 is stored. Cookie siem_session, HttpOnly, SameSite=Lax, 12 hours, Secure when the request is HTTPS.
Lockout8 failed logins for the same username + IP in 15 minutes → HTTP 429. Dummy Argon2 still runs on unknown usernames so timing does not leak whether the name exists.
Password changeRequires the current password. All other sessions for that user are revoked. A new cookie is issued to the browser that just rotated.
Admin resetAdmin sets a new password for someone else. That user’s sessions die. They sign in again.
CSRFMutating auth routes require Content-Type: application/json. Combined with SameSite=Lax, a cross-site form post cannot log in or create users.

With nginx

Once operator accounts exist, the dashboard uses the session cookie. nginx may still replace Authorization with the ingest Bearer (see 15) — that header is ignored for UI APIs. Keep basic auth if you want two gates. Deny /api/ingest on the public vhost either way.

/login, /api/login, and /api/setup stay reachable through the proxy so the first admin can be created and people can sign in.

Do not

  • Reuse the ingest token as an operator password
  • Leave SIEM_ADMIN_PASSWORD in the env file after first boot
  • Grant user-admin to anything that only knows the ingest token
  • Commit usernames, hashes, or session cookies
  • Expose --listen 0.0.0.0 with zero users and no firewall
