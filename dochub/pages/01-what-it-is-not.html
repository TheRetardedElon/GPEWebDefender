01 · What it is not

Boundary chapter. If a feature is not in this table as “ours,” do not assume it. This is how we avoid becoming Wazuh by accident.

Reviewed 2026-08-14 Not OSSEC source Not a WAF

Not these products

NotWhy people think it isReality
OSSEC We started the conversation on github.com/ossec/ossec-hids. Zero OSSEC files, XML, or analysisd. New Go program.
Wazuh Wazuh is the OSSEC fork people actually deploy. We refused OpenSearch and the Java indexer on purpose.
A WAF It talks about SQLi and XSS. It does not sit in the request path. Optional containment (ch. 20) tells that host’s firewall to drop an IP after an admin clicks. Not a proxy, not automatic.
A full SIEM The repo is named SIEM. No FIM, no rootkit, no Windows Event Log, no cases/IR workflow, no threat-intel feed.
CrowdSec / fail2ban It notices brute force. It is not a bouncer. After you pair a sensor (ch. 20), an admin can ask that host’s fail2ban / UFW / Windows Firewall to drop one public IP. No auto-ban from a rule.
Grafana / Kibana There is a dashboard. One embedded HTML page. Not a charting platform.

Not these capabilities (v0.1)

CapabilityStatusWhere it would live if we add it
POST body inspection No Would require app/WAF audit logs. Do not dump bodies into access.log (PCI).
File integrity monitoring No Agent rewrite. Not this product slice.
SSH / auth.log Limited sshd / sudo / PAM / console only. Not a general syslog SIEM. See 16.
Active block (iptables / nft) No Response chapter. Monitor first.
Cloudflare / WAF log ingest No 12 · Roadmap
GeoIP No Needs a MaxMind (or similar) DB. Optional later.
LLM “SOC analyst” No Not until the sensor is boring and trusted.
Name trap Calling it a SIEM in the folder is fine. Selling it as Splunk/Wazuh is not. Internally: “web-attack monitor.” Externally: same words, unless we grow the product.

What we will not add “just because”

  • OpenSearch / Elasticsearch / Graylog as a dependency.
  • A JVM for any reason.
  • Logging request bodies that might contain PAN, passwords, or gift-card PINs.
  • A public UI with no token on a product host.
