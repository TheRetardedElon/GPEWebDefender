Store & retention

TableWhatRetention
events Every parsed request --retain (default 168h). Pruned every 30 minutes.
alerts Rule hits Kept 4× event retain so the SOC view still has history.
Why SQLite Pure Go driver (modernc.org/sqlite) so Windows and Linux cross-compile with CGO_ENABLED=0. For a single platform this is enough. We do not start a search cluster until events outgrow a file. See 11.
