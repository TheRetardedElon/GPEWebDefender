14 · Snoop & canaries

A person typing /admin, then /.env, then /swagger.json every few seconds is not ffuf. This chapter is how we tell those apart, what else we watch on a web platform, and how trap paths give you a near-zero false-positive page.

Human vs scanner

Automated bustManual snoop
Cadence Tens–hundreds of req/s, almost no jitter One hit every 2–15s, messy pauses
Assets Almost never loads CSS/JS/images Address-bar / Burp: also no assets. Real browser tour: lots of assets
Referer Empty or the tool’s own Empty when they type the URL
Our rule web.scan.404storm — 25 × 404 / 60s web.snoop.slow404 / web.snoop.secret_hunt — 4–5 distinct interesting paths, median gap ≥ 1.5s, low asset ratio
Both can be true A nuclei run still lights scanner-UA + individual /.env rules. A bored human never hits 25 requests a second, so they never look like a storm. That is the point of kind: snoop.

Canaries (you plant them, we watch)

The SIEM cannot inject HTML into your app. You add a decoy; we alert on the first GET. One hit is enough. Severity is critical on purpose.

Plant this on the siteWe alert on
robots.txt → Disallow: /super-admin-backup-2026/ web.canary.robots_trap
HTML comment: <!-- debug: /internal-sync/v1 --> web.canary.internal_sync
A route that 403s /backup.zip (do not serve a real dump) web.canary.fake_archive
A 404/403 at /.well-known/siem-canary, /__canary__/siem, or /api/public/__siem-canary__ web.canary.well_known

If the application can POST structured events, send kind=secprobe and reason=canary_hit instead of hoping the access log path matches. See 16.

Add your own / optional packs Drop YAML in rules/ or --rules. packs/cms.yaml is WordPress / Drupal / Joomla paths — load it with --rules packs only if you want those. Any path your real users never touch is a good canary.

What access logs still cannot see

  • POST GraphQL bodies — introspection in the body only shows up if you log the query string or a WAF field.
  • Spoof headers (X-Original-URL) — only if your JSON access log includes them.
  • Burp vs Chrome — we infer from cadence + assets + referer, not from TLS JA3.
