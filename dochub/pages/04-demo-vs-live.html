04 · Demo vs live

The dashboard you opened first was a simulator. This chapter is the permanent reminder so nobody pages the team over a fake sqlmap hit.

Reviewed 2026-08-14 Demo never touches GPE

How to tell

DemoLive
Command gpewebdefender demo gpewebdefender serve --tail … or agent
DB file gpewebdefender-demo.db gpewebdefender.db (unless you override --db)
Source column demo Log file base name, or agent --name
IPs Hard-coded lab ranges (185.220…, 45.155…, 10.0.4.22, …) Whatever nginx wrote
Network None. internal/demo formats strings in-process. Reads a file. Agent POSTs to the manager. Still no outbound scan of your site.
Startup log DEMO mode — simulated web attacks on http://… web attack monitor on http://… (N rules) + tailing …
Demo is not a load test of the real site It does not issue HTTP to any host. If you want to see real internet noise, point --tail at a real access log.

What demo invents

Code: internal/demo/demo.go. Mix of clean site paths and classic probes.

Going live without mixing files

  1. Stop demo (Ctrl+C).
  2. Do not reuse gpewebdefender-demo.db as the live DB.
  3. gpewebdefender serve --tail /var/log/nginx/access.log --db /var/lib/gpewebdefender/gpewebdefender.db
  4. Confirm source is the file name, not demo.
