How an IP becomes a dot

  1. Private / loopback / link-local → no plot (your LAN is not an attacker country).
  2. Built-in pin table (demo IPs and a few well-known scanner ranges) → ISO country → centroid + slight jitter.
  3. Optional --geoip /path/to/GeoLite2-City.mmdb (or Country, or a DB-IP MMDB) → real country/city.
gpewebdefender serve --tail /var/log/nginx/access.log --home US --geoip /var/lib/gpewebdefender/GeoLite2-City.mmdb
gpewebdefender serve --home 40.7,-74.0 --homes "web-1=40.7,-74.0;edge-eu=51.5,-0.12"
gpewebdefender demo --home 40.7,-74.0
We do not ship a GeoIP file MaxMind GeoLite2 needs their license (free). DB-IP publishes a country lite MMDB with attribution. Drop the file next to the binary and pass --geoip. Demo mode does not need it — pins cover the fake IPs.

The UI default is All hosts — every configured pin, every source. Pick a name in the header to isolate one box. The choice is stored in localStorage, not on the server.
