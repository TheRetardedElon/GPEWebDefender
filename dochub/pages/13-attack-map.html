13 · Attack map

A shot fires from the attacker to the host you are defending — only when that alert happens. Same idea as a public “threat map,” without a globe SaaS or a Java stack. It plots alerts we already fired — not a second sensor. No standing tracks.

What it shows

WidgetSource
BasemapEmbedded world plate. Scroll to zoom, drag to pan, Hosts zooms to your pins, World resets. Hover a pin for country / IP.
Attack shotOn a live alert (SSE, or a new row the poller has not seen). Arc grows from the attacker pin to the matching host, comet at the tip, brief fade on impact — then gone. Nothing stays drawn on that path.
Host pinsEvery named home stays on the map (rack / edge / datastore / terminal art). The host dropdown still filters the feed and shots; unselected pins dim. Hosts zooms to the selected box, or all of them.
Host pickerDropdown: one source, or all homes at once. Shots land on the pin that matches X-SIEM-Source.
Origin countriesCounts from alerts in the last 24h
Type keyColor = category (SQLi, snoop, canary, scanner…). Click to filter map + feed.
Origin countsLast-24h unique origins from GET /api/map. Used for the key / legend, not as standing beams.
IconsEmbedded ui/icons/: host silhouettes, country plates, attack-type marks. Event inspect card and reports reuse the same files. Missing country art falls back to the name only.

It does not ingest WAF engines, nftables, or Layer-4 PCAP. Those are later sensors. The map is attribution for the web-attack feed you already have.

How an IP becomes a dot

  1. Private / loopback / link-local → no plot (your LAN is not an attacker country).
  2. Built-in pin table (demo IPs and a few well-known scanner ranges) → ISO country → centroid + slight jitter.
  3. Optional --geoip /path/to/GeoLite2-City.mmdb (or Country, or a DB-IP MMDB) → real country/city.
gpewebdefender serve --tail /var/log/nginx/access.log --home US --geoip /var/lib/gpewebdefender/GeoLite2-City.mmdb
gpewebdefender serve --home 40.7,-74.0 --homes "web-1=40.7,-74.0;edge-eu=51.5,-0.12"
gpewebdefender demo --home 40.7,-74.0
We do not ship a GeoIP file MaxMind GeoLite2 needs their license (free). DB-IP publishes a country lite MMDB with attribution. Drop the file next to the binary and pass --geoip. Demo mode does not need it — pins cover the fake IPs.

--homes "a=40.7,-74.0;b=DE"One pin per agent name. Semicolon-separated because lat,lon already uses a comma. Close pins are fanned out so they do not stack.

The UI default is All hosts — every configured pin, every source. Pick a name in the header to isolate one box. The choice is stored in localStorage, not on the server.
