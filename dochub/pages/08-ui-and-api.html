HTTP API

MethodPathAuthNotes
GET/docs/openThis DocHub (if installed next to the manager)
GET/api/healthopenok, seen, fired, drop, rules
GET/api/maptoken if setHome pin(s), arcs, country counts. Query: since, limit, source. See 13.
GET/api/sourcestoken if setDistinct agent names + configured homes. Feeds the host dropdown.
GET/api/reports/vectorstoken if setsince, source. Category, severity, host, MITRE, path, country, adaptive time buckets, top IPs.
GET/api/export/alertssession (or token if no users)Same window as Insight. format=csv|json, since, source. Max 5000 rows. Attachment, Cache-Control: no-store. Does not include the ingest token or operator accounts.
GET/api/export/eventssession (or token if no users)Auth / probe channel rows. channel=web|linux|app|tenant|probes, same format flags.
GET/api/intelsession (or token if no users)ip, since. Local threat weight + intent from our alerts. Optional slow AbuseIPDB trickle if ABUSEIPDB_KEY is set (~90s, cached). Browser links for the other sites. No HTML scraping.
GET/api/reports/authtoken if setchannel=web|linux|app, since, source.
GET/api/reports/blockssessionCurrent blocklist: IP, host, why (alert title/number), applied/failed/queued, time left, hits after ban.
GET/api/statussessionLast host snapshots. No live scrape. See 21.
POST/api/status/check, /api/agents/{id}/check, /api/agents/check-alladmin sessionRequest one snapshot. Manager answers immediately. Paired sensors answer on the next command poll.
POST/api/agent/statsthat host’s pair keySensor posts the snapshot. Ingest token cannot.
GET/api/statstoken if setDashboard snapshot. Query: source
GET/api/alertstoken if setPaged. Query: q (also #123), severity, ip, source, since, limit, before/after (alert number). Body: {alerts,has_more,oldest_num,newest_num}
GET/PUT/api/settingssession (admin to PUT)Site name, home, homes, retain, timezone. Token and listen stay in flags/env.
GET / POST/login, /api/login, /api/setup, /api/users, /api/mesee 18Operator accounts. Ingest Bearer does not unlock these after the first user exists.
GET/api/searchsession (or token if no users)FTS5. Query: q, ip, host, source, kind, limit, sort=newest|oldest (default newest). Click When in the UI to flip it.
GET/api/eventstoken if setq, ip, source, limit
GET/api/attackerstoken if setsince, limit, source
GET/api/rulestoken if setLoaded rule metadata (no regex text)
GET/api/streamtoken if setSSE. Events: ping, alert
POST/api/ingesttoken if setPlain lines, JSON string array, one Event, or Event batch. Header X-SIEM-Source. A paired host key also works after Approve (name is forced).
POST/api/agent/pairopen, rate-limitedPhrase + one-time code + host name. See 20.
GET/api/agent/commandsthat host’s keyOnly after Approve. ban / unban / list / stats.
POST/api/pair-phrase, /api/pair-codes, /api/agents/…admin sessionMint codes, approve, revoke, ban. Viewer cannot. Ingest token cannot.

Ingest token: Authorization: Bearer SECRET or ?token=SECRET on /api/ingest only (after operator accounts exist). Empty --token with zero users means the API is open to anyone who can reach the bind address. People use a session cookie — 18.

Ingest examples

curl -s http://127.0.0.1:8787/api/health

curl -sH "Authorization: Bearer SECRET" ^
  --data-binary @access.log ^
  -H "X-SIEM-Source: edge-nginx" ^
  http://127.0.0.1:8787/api/ingest
