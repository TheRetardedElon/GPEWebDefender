10 · Deploy

Dedicated monitor box + a tiny agent on each host that has access logs. Bind the manager to localhost. Do not put real hostnames, IPs, or secrets in docs or git. If you want the script to do this, start at 03 · Method A. This page is the same thing, written out.

Box size

A 2 vCPU / 2 GB RAM Linux VPS is plenty. The manager idles around a few megabytes of RSS. Disk: SQLite + WAL; 20 GB is already generous. Put it on its own box so a monitor crash cannot touch the web app.

Only machines that write HTTP access logs need an agent. Settlement nodes, build boxes, and databases do not generate web-attack telemetry.

Manager (monitor box)

Fast path: sudo ./deploy/install-manager.sh (see 03). Slow path, so you can see every file:

  1. Copy the Linux binary to /usr/local/bin/gpewebdefender.
  2. System user gpewebdefender, home /var/lib/gpewebdefender.
  3. Copy rules/*.yaml to /var/lib/gpewebdefender/rules (cwd of the service).
  4. Copy this DocHub to /var/lib/gpewebdefender/dochub.
  5. Copy deploy/env.example to /etc/gpewebdefender/env (mode 640). Put a long random value in GWD_TOKEN. Do not paste it into git or this page.
[Unit]
Description=gpewebdefender web-attack monitor
After=network.target

[Service]
Type=simple
User=gpewebdefender
Group=gpewebdefender
WorkingDirectory=/var/lib/gpewebdefender
EnvironmentFile=/etc/gpewebdefender/env
ExecStart=/usr/local/bin/gpewebdefender serve \
  --listen 127.0.0.1:8787 \
  --db /var/lib/gpewebdefender/gpewebdefender.db \
  --home 40.7,-74.0 \
  --token ${GWD_TOKEN} \
  --retain 168h \
  --docs /var/lib/gpewebdefender/dochub
Restart=on-failure
RestartSec=2

[Install]
WantedBy=multi-user.target

/etc/gpewebdefender/env is one line: GWD_TOKEN=… generated on the box. --home is the defended site (map pin), not the monitor’s city. Do not --tail on the manager if logs live on other hosts.

Firewall Allow SSH. Do not allow 8787 from the internet. If agents must reach ingest, allowlist only those host IPs (keep them out of git).

Agent (each web host)

Fast path (logs only): sudo ./deploy/install-agent.sh --url http://MONITOR:8787 --name web-1 --tail /var/log/nginx/access.log --journal

Same script with pairing: add --code ABCD-2341 --block fail2ban after you mint a code in Settings. Chapter 20. After Approve, Status → Check now also works on that host (ch. 21).

# token lives in /etc/gpewebdefender/env as GWD_TOKEN=…
gpewebdefender agent \
  --url http://MONITOR_INTERNAL:8787 \
  --token "$GWD_TOKEN" \
  --cred /etc/gpewebdefender/agent.json \
  --tail /var/log/nginx/access.log \
  --journal \
  --name web-1

Prefer a private NIC, VPN, or SSH tunnel over exposing ingest. --name is the label in the UI. Same binary as the manager.

Docs on the box

If ./dochub/index.html exists in the working directory, the manager serves this DocHub at /docs/. The live UI has a Docs link in the header.
