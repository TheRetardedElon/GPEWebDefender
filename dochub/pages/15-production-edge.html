Three different secrets

SecretWhoLives
Operator accountHumansArgon2id in the manager SQLite. Create / rotate in Settings. 18.
UI basic auth (optional)Humansnginx htpasswd. A different password from Settings users. Turn it off after operator accounts exist or you will get a browser popup that rejects those users.
Ingest tokenManager + agents/etc/gpewebdefender/token and /etc/gpewebdefender/env (mode 640). Never grants user-admin.

Basic + Bearer (do this or the UI 401-loops)

nginx basic auth and the ingest token both want the Authorization header. After operator accounts exist, the dashboard uses a session cookie and does not need Bearer on UI APIs. If you still inject Bearer (so the pre-account bootstrap and any leftover clients keep working), that is fine — ingest Bearer is ignored for everything except /api/ingest. See deploy/nginx-gwd.conf.example. Agents never use the public HTTPS ingest path.

Agents

Same binary. Hosts with HTTP access logs: --tail. Linux boxes you also want SSH/sudo on: add --journal. A machine with neither does not need an agent. Adding a box is a short checklist in 17.

deploy/gpewebdefender-agent.service.example — copy, fill, enable.

GeoIP

Drop a country/city .mmdb at /var/lib/gpewebdefender/geoip.mmdb (or pass --geoip). The manager loads it automatically. Without it the feed still works; the map will not invent countries for real IPs. DB-IP lite is fine; keep their attribution if you use it.

Do not

  • Hardcode anyone’s hostnames, IPs, or tokens in this repo
  • Open the ingest port to the whole internet
  • Expose /api/ingest on the public HTTPS vhost
  • Ship OSSEC/Wazuh “for completeness”
  • Treat the ingest token as a human login, or leave SIEM_ADMIN_PASSWORD in the env file
  • Wrap the Go binary in PM2 / Node. systemd already restarts it. Use siem restart from deploy/siem.example.
