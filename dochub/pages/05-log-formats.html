05 · Log formats

Parser lives in internal/parse. JSON first if the line starts with {, then nginx/Apache combined, then vhost_combined, then syslog auth.log (sshd / sudo / PAM only).

Reviewed 2026-08-14 Prefer JSON

Combined (default nginx / Apache)

203.0.113.9 - - [14/Aug/2026:12:00:01 +0000] "GET /api/users?id=1%20UNION%20SELECT%20password HTTP/1.1" 200 512 "https://example.com/" "sqlmap/1.8"

Time layout: 02/Jan/2006:15:04:05 -0700. Optional quoted referer + UA. Vhost form (host ip - user [time] …) is tried second so the optional host cannot steal the IP.

JSON (recommended)

Field names are a union of nginx, Caddy, and Traefik. Caddy’s nested request object is flattened.

We look forTypical keys (first hit wins)
Source IPremote_addr · remote_ip · client_ip · src_ip
URLrequest_uri · uri · url · path · request
Methodrequest_method · method
Statusstatus · status_code
UAhttp_user_agent · user_agent
Timetime_iso8601 · RFC3339 · unix seconds/ms

nginx snippet

log_format json_siem escape=json
  '{'
    '"remote_addr":"$remote_addr",'
    '"request_method":"$request_method",'
    '"request_uri":"$request_uri",'
    '"status":$status,'
    '"body_bytes_sent":$body_bytes_sent,'
    '"http_user_agent":"$http_user_agent",'
    '"http_referer":"$http_referer",'
    '"host":"$host",'
    '"time_iso8601":"$time_iso8601"'
  '}';
access_log /var/log/nginx/access.json json_siem;
Do not add the body $request_body will eventually log a card number or a password. Access-log SIEM is URL + UA + status. That is the contract. See 11.

Decode

Matching runs on DecodeForMatch(path, query) — up to two url.QueryUnescape passes so %252e%252e and %27or%271 become visible. Evidence in the UI is clipped around the regex hit.

What we drop

  • Blank lines and # comments (IIS-style headers).
  • Lines that match neither JSON nor combined — counted on /api/health as drop.
